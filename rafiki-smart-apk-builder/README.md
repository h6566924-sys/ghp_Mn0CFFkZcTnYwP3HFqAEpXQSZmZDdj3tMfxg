# محرك رفيقي الذكي لبناء APK

نسخة Next.js/Vercel بواجهة عربية RTL، وتستخدم GitHub Actions لبناء APK فعلي.

## إعداد Vercel

أضف متغيرين في Vercel:

```text
GITHUB_REPO=rafiki-apk-builder
SESSION_SECRET=ضع_هنا_سلسلة_عشوائية_طويلة_32_حرفًا_على_الأقل
```

لا تضع مفتاح GitHub في `NEXT_PUBLIC_*` ولا داخل الكود. الموقع يحفظ المفتاح في cookie مشفرة HttpOnly.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح الموقع، الصق مفتاح GitHub، واضغط «حفظ والتحقق»، ثم «تجهيز المستودع تلقائيًا».

## الصلاحيات المطلوبة

الموقع يحتاج مفتاحًا قادرًا على قراءة/كتابة المستودع وتشغيل GitHub Actions. تعديل ملف workflow يحتاج صلاحية Workflows، وتشغيل workflow يحتاج Actions write، وإنشاء Release يحتاج Contents write.

## مبدأ كشف الملفات

لا يوجد في Workflow `test -f` لملف تم افتراض وجوده في كل مشروع. الملفات الضرورية لا يتم طلبها إلا بعد اكتشاف نوع المشروع من الملفات الموجودة فعلًا. عند عدم توفر إعداد يمكن استخدامه، يفشل البناء بسبب حقيقي ومحدد بدل البحث عن ملفات غير موجودة أو إعلان نجاح وهمي.

## المحركات المخصصة

ZIP المحرك يجب أن يحتوي:

```text
engine.json
build.sh
```

ويُنفّذ `build.sh` داخل GitHub Actions في مستودعك بعد أن تختاره يدويًا من الواجهة.
